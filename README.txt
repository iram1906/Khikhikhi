FOR BUDDY — BOYFRIEND'S DAY WEBSITE

Files:
- index.html = opening page
- chapter01.html through chapter26.html = actual separate pages
- style.css = shared design

GitHub Pages setup:
1. Upload ALL files to the same repository root.
2. Make sure index.html is directly in the root, not inside another folder.
3. Settings → Pages → Deploy from branch → main → /(root).
4. Open the Pages URL.
5. Start from the URL without /chapter01.html.

This version uses no JavaScript and no external libraries/fonts.
Every navigation button is a normal HTML link.
